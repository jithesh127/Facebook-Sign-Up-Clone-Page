# Facebook Sign Up Page Clone

## Description
This project is a simple Facebook Sign Up Page Clone developed using HTML and CSS. It replicates the basic registration interface of Facebook with a clean and user-friendly design.

## Features
- User registration form.
- First name and last name fields.
- Mobile number or email input.
- Password field.
- Date of birth selection.
- Gender selection.
- Sign Up button.
- Responsive and clean user interface.

## Technologies Used
- HTML5
- CSS3

## Purpose
This project was developed for front-end web development practice to improve HTML form creation and CSS styling skills.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Run `index.html` in your web browser.

## Note
This is a frontend practice project only. It does not include a real backend or user authentication system.
