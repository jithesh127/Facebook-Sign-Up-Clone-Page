# Facebook Sign Up Page Clone

## Description

This project is a Facebook Sign Up Page Clone developed using HTML, CSS, JavaScript. It provides a registration form with a design similar to Facebook's sign-up page.

## Features

- First name and surname input fields.
- Mobile number input field.
- Password input field.
- Date of birth selection (Day, Month, Year).
- Gender selection.
- Sign Up button.
- Form validation using jQuery Validation Plugin.
- Required field validation.
- Minimum 5 characters validation for the first name.
- Custom error messages for first name validation.

## Technologies Used

- HTML5 – Page structure.
- CSS3 – Styling and layout.
- JavaScript – Interactive functionality.
- jQuery – Simplifies JavaScript operations.
- jQuery Validation Plugin – Form validation.

## Validation

- First name is required and must contain at least 5 characters.
- Surname is required.
- Mobile number is required.
- Password is required.
- Date of birth fields are required.
- Gender selection is required.

## Purpose

This project was created to practice frontend web development, form creation, and client-side form validation.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Note

This is a frontend practice project. It does not include backend integration or real user authentication.
