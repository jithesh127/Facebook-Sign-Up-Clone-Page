# Facebook-Inspired Sign-Up Form | Frontend Project

A frontend practice project recreating a sign-up form layout to practise form design, input handling, and client-side validation.

> **Educational project only.** This is not affiliated with or endorsed by Facebook. It does not create accounts or provide real authentication.

## Technologies
**HTML5 · CSS3 · JavaScript · jQuery · jQuery Validation Plugin**

## Features
- Sign-up form fields for name, mobile number, password, date of birth, and gender.
- Required-field validation.
- First-name minimum-length validation (5 characters).
- Custom validation messages to guide form input.

## Implementation Focus
- Structuring form elements with HTML.
- Styling the interface with CSS.
- Using JavaScript and jQuery for client-side interactions.
- Applying validation rules to improve input feedback.

## Run Locally
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Scope & Limitations
This is a client-side demonstration only. It has no backend integration, account storage, or authentication. Do not enter real personal information.
